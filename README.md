# استقبال الجامعة على روبوت تيمو

برنامج استقبال لروبوت [Timo AI](https://www.alpharobotics.ai/product-detail1/timo-ai-service-robot.html) على شاشته اللمسية 13.3 بوصة. يتحدث بالعربية والإنجليزية، ويعرّف بالجامعة ورؤيتها وخدماتها، ويعرض الكليات والأقسام والمرافق، ويستقبل الطالب والزائر بعبارة خاصة، ويمكن تلوين الواجهة ووضع شعار الجامعة.

المحتوى الافتراضي نموذج باسم **جامعة المعرفة** حتى يعمل البرنامج فورًا. استبدلوه ببيانات جامعتكم من شاشة «إعداد المؤسسة» أو من ملف `content/university.json`.

## الوظائف

| المطلوب | أين يعمل |
| --- | --- |
| التعريف بالجامعة ورؤيتها وخدماتها | الشاشة الرئيسية، والأسئلة مثل «عرفني عن الجامعة» و«ما رؤية الجامعة» |
| العربية والإنجليزية | زرّا اللغة، واكتشاف لغة السؤال، وعبارة «بالعربي» أو `english please` |
| الكليات والأقسام والمرافق | البطاقات، وأسئلة مثل «كلية الهندسة» و«وين المكتبة» |
| الهوية البصرية | الشعار والألوان والاسم من إعداد المؤسسة، وتُطبَّق فور الحفظ |
| ترحيب الطلبة والزوار | `approach("visitor")` و`approach("student")` مع صباح الخير / طاب يومكم / مساء الخير |
| نصوص المؤسسة | كل النصوص في ملف واحد، مع استيراد وتصدير وتحقق من اكتمال العربية والإنجليزية |

الملاحة بالليزر وتفادي العوائق والعودة للشحن تبقى في نظام تيمو. هذا البرنامج يرسل رقم نقطة الخريطة عندما يُربط الروبوت، ويعرض مكان الجهة على الشاشة في كل الأحوال. التعرف على الوجه، إن كان مفعّلًا في تيمو، يستدعي الترحيب المناسب فقط؛ التطبيق لا يستقبل صور الوجوه ولا يخزنها.

## التشغيل

```bash
npm test
npm start
```

ثم افتحوا `http://localhost:8080` على الشاشة الصدرية أو في المتصفح. للتجربة مع جسر الروبوت الوهمي: `http://localhost:8080/?native=1`.

رمز إعداد المؤسسة: `2468`. هو قفل محلي للشاشة وليس حماية شبكة. غيّروه من قسم الملف بعد الدخول.

من الإعداد يمكن تعديل الاسم والرؤية والرسالة والخدمات والكليات والأقسام والمرافق ورسائل الترحيب والألوان والشعار، ثم تصدير المحتوى أو قاعدة المعرفة. الحفظ يبقى على الجهاز نفسه.

لإخفاء أزرار «اقتراب زائر / طالب» على الروبوت الحقيقي، ألغوا خيارها في الإعداد. الربط الحقيقي يستدعي الدوال مباشرة.

## الربط مع تطبيق تيمو

من صفحة الروبوت:

```javascript
TimoUniversity.approach("visitor");
TimoUniversity.approach("student");
TimoUniversity.leave();
TimoUniversity.hear("وين المكتبة");
TimoUniversity.setLanguage("en");
```

وإذا وفّر تطبيق أندرويد الجسر التالي، يتكلم البرنامج عبر سمّاعة الروبوت ويطلب الملاحة:

```javascript
window.TimoHost = {
  speak(text, lang) {},
  navigate(mapPoint) {},
};
```

أسماء نقاط الخريطة الجاهزة، مثل `facility-library` و`college-engineering` و`main-gate`، موجودة في `dist/waypoints.json` بعد تشغيل:

```bash
npm run export
```

أنشئوا النقاط بنفس الأسماء في خريطة تيمو، أو غيّروا الحقل `mapPoint` داخل الملف. ملفات التسليم الأخرى:

- `dist/knowledge-base.csv` و`dist/knowledge-base.json` لقاعدة معرفة تيمو إن بقيتم على حوار الشركة
- `dist/welcome-scripts.md` لنصوص الترحيب والوداع
- `dist/theme.json` للشعار والألوان

ضعوا عنوان الصفحة كصفحة البداية في متصفح الروبوت، أو داخل WebView مع `JavascriptInterface` باسم `TimoHost` ودالتي `speak` و`navigate`.
